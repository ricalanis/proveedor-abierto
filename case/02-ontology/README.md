# Phase 2 outputs (versioned)

- `factors.yaml`: factors of variation, with human accept/reject
- `taxonomies/`: one file per factor taxonomy (depth 2 for the hackathon)
- `sampling-strategies.yaml`: strategies and mixes
- `schema/`: ontology (Turtle), SHACL shapes (incl. red-flag rules), alignment to OCDS / schema.org / Wikidata
- `dod-queries/`: definition-of-done criteria compiled to SPARQL
- `recommendations/`: evidence-backed change proposals filed by Phase 4
- `CHANGELOG.md`: ontology versions; an accepted change triggers re-refinement from bronze
