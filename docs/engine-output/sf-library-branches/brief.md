# SF library branches

Which San Francisco Public Library branches offer free Wi-Fi, and when is each one open? List every branch with its address, its weekly opening hours and whether it offers free public Wi-Fi, and show the source for each value.

## Constraints and notes

Public, read-only sources only. San Francisco, California, USA. The San Francisco Public Library's own website (sfpl.org) is the primary publisher for branches, hours and Wi-Fi; a value it publishes needs no second source. San Francisco's open data portal (data.sfgov.org) is a secondary cross-check for branch addresses only. Done means every branch listed with address, weekly hours and Wi-Fi (yes/no), each value with evidence.
