Zero open ports, gated by role

NetBird criterionOur setup
No open portsBoth VMs allow zero public inbound ports, SSH included. Public URLs go through the NetBird reverse proxy.
Gated by roleViewers: the product and a read-only console (writes refused, 403). Approvers: the Ontofill Console via SSO, approvers group only.
Peer-to-peerControl and sandbox VMs talk over WireGuard. The sandbox group reaches one control port, one way.
Lifecycle-bound URLsEach browser session's live view gets its own NetBird expose that stops existing when the session closes.
