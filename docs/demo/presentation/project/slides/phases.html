Every decision inside a run is a Vultr inference call. A person's approval is bound to the sha256 of the exact file they reviewed, and a deny with a reason makes the engine redraft.

Nobody edits a run by hand. A defect is fixed in code, then the run resumes or reruns.

The runner service resumes a run on its own after each console decision. Human inputs are the brief, approvals, and start, pause or the kill switch.
