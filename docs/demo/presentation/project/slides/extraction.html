Each (source, objective) gets a technical plan: target properties, path, allowed domains, budget and the range of execution modes. Execution starts at the cheapest mode and climbs only when a check fails. Every capture lands in bronze and is never overwritten, so a changed ontology re-refines gold from bronze without browsing again. Failing extractors repair themselves in a networkless cell and become macros, so the next run is cheaper. Gold is what the definition of done is measured on; a gap reopens discovery, the plan or the ontology, and an ontology change always goes back to a person.
