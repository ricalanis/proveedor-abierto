Research ledger, leads, sandbox captures

2 · PROPOSE

Planner (glm-5.3) drafts, best of N

3 · CRITIQUE

A critic from another model family objects

4 · REVISE

The draft answers each objection

5 · CHECK IN CODE

Exit criteria compiled to code; loop until they pass, within budget

6 · HUMAN GATE

TYPED DECISIONS

Models choose within typed options; code owns order, budgets and stops

deny + reason → redraft

Every phase runs the same bounded loop. The planner (glm-5.3) proposes; a critic from a different model family (minimax-m3 or qwen3.8-27b) raises objections such as invented targets, infeasible budgets or missing coverage; the draft is revised; code checks the phase's exit criteria. It stops when the checks pass and the critic has no blocking objection, or when the budget runs out, and then shows the open issues. A person's deny with a reason becomes a human revision the loop can never override. All of it runs on Vultr Serverless Inference, and every iteration is a trace event on the console.
